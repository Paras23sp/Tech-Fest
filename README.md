# Tech-Fest
PriceProof — Compare the Real Cost

About the Project

PriceProof is a product price comparison website that helps users compare online shopping offers based on their total expected cost, rather than just the displayed product price.

Problem Statement

Different shopping platforms may have different delivery fees, discounts, return policies, and warranty conditions. Comparing only the listed price can make it difficult to identify the best overall deal.

Our Solution

PriceProof provides a simple interface to compare product offers, view additional charges, and understand return and warranty conditions before making a purchase decision.

Key Features

- Product search and category-based browsing
- Comparison of multiple offers
- Total cost calculation using available prices and fees
- Sorting offers to identify lower-cost options
- Return and warranty information
- Responsive design with smooth animations
- Product images on comparison cards

Technology Stack

- HTML — webpage structure
- CSS — styling, responsive layout, and animations
- JavaScript — search, product data, calculations, and comparison logic


Current Limitations

- The current prototype uses demonstration product data and prices.
- Live Amazon and Flipkart API integration is not yet implemented.
- Delivery charges, return fees, and warranty details may be unavailable for some offers.
- Displayed comparisons are intended to demonstrate the concept and are not verified live shopping prices.

Future Improvements

- Integrate authorized shopping APIs.
- Retrieve updated product information and prices.
- Improve delivery fee and return policy comparisons.
- Add more shopping platforms and product categories.
