# PriceProof — Hackathon MVP

## Run
1. Extract `PriceProof_Hackathon_MVP.zip`.
2. Open the `PriceProof` folder.
3. Double-click `index.html` to open it in a browser.

No build tools or API keys are needed for this demo.

## Included
- Searchable demo catalogue: headphones, mouse, keyboard, laptop, monitor, phone, earbuds
- Three fictional offers per category
- Total known cost and sorting
- Return/warranty information and caveats
- Responsive desktop/mobile UI

## Important limitation
This MVP uses fictional demo data. It does not fetch live Amazon, Flipkart, or other retailer prices. Real integrations require an authorised API/feed and any required credentials/approval. The interface labels the data as demo data to avoid misleading users.
